# Uno-Dos-Tres-Fight
Карточный тактический рогалик, объединяющий базовые правила UNO с механикой асимметричных модификаторов.

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Идея проекта и геймплей (MVP)

Игрок проходит цепочку дуэлей против ИИ-боссов, используя модифицированную колоду UNO. Вместо классического подсчета очков победа в раунде наносит урон здоровью противника (или открывает путь дальше), а между боями правила игры постоянно меняются.

## Ключевые механики
* **Базовое ядро UNO:** Карты разыгрываются по совпадению цвета или номинала/типа. Числовые карты определяют силу атаки/взаимодействия, а специальные карты («+2», «+4», «Реверс», «Пропуск хода», «Смена цвета») дают тактическое преимущество.
* **Рогалик-прогрессия (Баффы и Дебаффы):** После каждой победы игрок выбирает **1 карту-артефакт** для усиления своей колоды, но одновременно с этим выбирает **1 усложнение** (усиление для ИИ-противника или изменение глобальных правил стола).
* **Data-Driven баланс:** Все параметры карт, эффекты артефактов и характеристики боссов вынесены в конфигурационные файлы (`JSON`), что позволяет гибко настраивать баланс без изменения исходного кода.

## Архитектура проекта

Проект строится по принципу четкого разделения игровой логики и графического интерфейса (паттерн **MVC / MVP**). Ядро игры реализовано в виде конечного автомата (**State Machine**) и системы событий (**Observer**), что позволяет легко подключать новые модификаторы правил.

### Структура репозитория
```text
├── data/                 # JSON-конфигурации карт, артефактов-модификаторов и врагов
├── docs/                 # Командный устав (team.md), схемы и документация проекта
└── src/
    ├── core/             # Игровое ядро (не зависит от движка и отрисовки):
    │   ├── Card          # Модель карты (цвет, номинал, базовый эффект)
    │   ├── Deck          # Управление колодой, рукой, сбросом и тасованием
    │   ├── Modifier      # Система пассивных эффектов и правил (логика Shotgun King)
    │   ├── AIController  # Эвристический алгоритм принятия решений для ИИ-босса
    │   └── GameState     # Конечный автомат (FSM) ходов и проверка условий победы
    └── ui/               # Слой представления (отрисовка стола, карт, анимации и ввод)
